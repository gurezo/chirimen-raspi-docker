## 目的

Raspberry Pi 3 / 4 / 5 で共通の、3.3V I2C1 に接続する ADS1115 4ch ADC 回路を 1 つに決める。

## ピン対応

| 役割 | BCM | 40-pin header 物理 pin | 備考 |
| --- | --- | --- | --- |
| SDA | `2` | `3` | I2C1。Pi 3 / 4 / 5 で同一 |
| SCL | `3` | `5` | I2C1。Pi 3 / 4 / 5 で同一 |
| 3.3V | — | `1` | 他の 3.3V ピンでも可 |
| GND | — | `6` | 他の GND ピンでも可。ADDR も GND へ（address `0x48`） |

```text
requestI2CAccess()
  → ports.get(1)
  → open(0x48)
  → ch0–ch3 を single-shot で読む（PGA ±4.096 V）
  → raw / 電圧表示
```

| 項目 | 値 |
| --- | --- |
| device | ADS1115 |
| address | `0x48`（ADDR = GND の default） |
| bus | I2C1（`/dev/i2c-1`、`ports.get(1)`） |
| PGA | ±4.096 V |
| 入力 | AIN0–AIN3 対 GND。入力電圧は 3.3V を超えない |

ADT7410 の既定アドレスも `0x48` である。同じバスに同時接続しない。

## 必要部品

| 部品 | 数量 | 仕様 |
| --- | --- | --- |
| ADS1115 | 1 | 16-bit 4ch ADC。ADDR を GND にして address `0x48` |
| ジャンパワイヤ | 4 本以上 | SDA / SCL / 3.3V / GND へ。アナログ入力は任意 |

モジュールに pull-up が無い場合は、SDA / SCL に 4.7kΩ を 3.3V へ上げる。未配線チャネルは GND に落とすか、表示値が不定であることを許容する。

## 配線

```text
3.3V (物理 pin 1)
  → ADS1115 VDD

SDA (物理 pin 3 / BCM 2)
  → ADS1115 SDA

SCL (物理 pin 5 / BCM 3)
  → ADS1115 SCL

GND (物理 pin 6)
  → ADS1115 GND
  → ADS1115 ADDR
```

アナログ入力（AIN0–AIN3）は測定対象へつなぐ。GPIO へ 5V を入れない。ADS1115 のアナログ入力定格を超えない（本回路の正は 0–3.3V）。

禁止:

- **5V ピン**（物理 pin 2 / 4）を GPIO / 3.3V I2C へ入れない
- ADT7410（既定 `0x48`）と同時接続しない

## Raspberry Pi 3 / 4 / 5 の pin assignment

| 確認項目 | 結果 |
| --- | --- |
| 40-pin header | SDA 物理 3、SCL 物理 5、3.3V 物理 1、GND 物理 6 |
| I2C | I2C1。`ports.get(1)`、`/dev/i2c-1` |
| 3.3V / 5V | モジュール電源は 3.3V。アナログ入力も 3.3V を超えない |
| Pi 固有特殊機能 | 40-pin I2C1 のみ |

机上確認は合格。`supportedRaspberryPi` は `["3","4","5"]`。実機結果は [#257](https://github.com/gurezo/chirimen-raspi-docker/issues/257)。

## 期待結果

配線後、HTML サンプル（`http://127.0.0.1:4173/ads1115/`）を開くと ch0–ch3 の raw と電圧が更新される。Runtime 未接続時や slave 未応答時はページ上にエラーが出る。
