本仕様の対象は **温度読み取り** である。I2C Scan（`i2c-detect` / `workspace/i2c-scan/`）とは別 Example。

## 目的

Raspberry Pi 3 / 4 / 5 で共通の、3.3V I2C1 に接続する ADT7410 温度読み取り回路を 1 つに決める。

## ピン対応

| 役割 | BCM | 40-pin header 物理 pin | 備考 |
| --- | --- | --- | --- |
| SDA | `2` | `3` | I2C1。Pi 3 / 4 / 5 で同一 |
| SCL | `3` | `5` | I2C1。Pi 3 / 4 / 5 で同一 |
| 3.3V | — | `1` | 他の 3.3V ピンでも可 |
| GND | — | `6` | 他の GND ピンでも可。A0 / A1 も GND へ |

```text
requestI2CAccess()
  → ports.get(1)
  → open(0x48)
  → 温度レジスタ 0x00 を 2 byte 読む
  → ℃ 表示
```

| 項目 | 値 |
| --- | --- |
| device | ADT7410 |
| address | `0x48`（A0 / A1 = GND の default） |
| bus | I2C1（`/dev/i2c-1`、`ports.get(1)`） |

ADS1115 の既定アドレスも `0x48` である。同じバスに同時接続しない。

## 必要部品

| 部品 | 数量 | 仕様 |
| --- | --- | --- |
| ADT7410 | 1 | I2C 温度センサ。A0 / A1 を GND にして address `0x48` |
| ジャンパワイヤ | 4 本以上 | SDA / SCL / 3.3V / GND へ |

モジュールに pull-up が無い場合は、SDA / SCL に 4.7kΩ を 3.3V へ上げる。

## 配線

I2C Scan の [検証用 slave 配線](./i2c-scan.md) と同じ。Scan は `writeByte(0x00)` の応答確認だけ、本 Example は温度レジスタを読む。

```text
3.3V (物理 pin 1)
  → ADT7410 VDD

SDA (物理 pin 3 / BCM 2)
  → ADT7410 SDA

SCL (物理 pin 5 / BCM 3)
  → ADT7410 SCL

GND (物理 pin 6)
  → ADT7410 GND
  → ADT7410 A0
  → ADT7410 A1
```

禁止:

- **5V ピン**（物理 pin 2 / 4）へ接続しない
- ADS1115（既定 `0x48`）と同時接続しない

## Raspberry Pi 3 / 4 / 5 の pin assignment

| 確認項目 | 結果 |
| --- | --- |
| 40-pin header | SDA 物理 3、SCL 物理 5、3.3V 物理 1、GND 物理 6 |
| I2C | I2C1。`ports.get(1)`、`/dev/i2c-1` |
| 3.3V / 5V | センサ電源は 3.3V |
| Pi 固有特殊機能 | 40-pin I2C1 のみ |

机上確認は合格。`supportedRaspberryPi` は `["3","4","5"]`。実機結果は [runtime-verification.md](./runtime-verification.md)（Pi 3 / 4 / 5 とも `unverified`）。

## 期待結果

配線後、HTML サンプル（`http://127.0.0.1:4173/adt7410/`）を開くと気温が ℃ で更新される。Runtime 未接続時や slave 未応答時はページ上にエラーが出る。
