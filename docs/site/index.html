chirimen-raspi-docker

Raspberry Pi 3 B+ / 4 / 5 で、ブラウザから GPIO / I2C を操作するための Docker ベース CHIRIMEN Runtime です。

推奨環境

Raspberry Pi OS Status
Raspberry Pi 3 B+ Raspberry Pi OS 64-bit Verified
Raspberry Pi 4 Raspberry Pi OS 64-bit Verified
Raspberry Pi 5 Raspberry Pi OS 64-bit Verified

Recommended: Raspberry Pi OS Lite 64-bit

32-bit OS は非推奨です。 詳細を見る
