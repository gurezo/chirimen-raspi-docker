chirimen-raspi-docker

Raspberry Pi 3 B+ / 4 / 5 で、ブラウザから GPIO / I2C を操作するための Docker ベース CHIRIMEN Runtime です。

Browser Development Flow

Learn → Edit → Save → Run → Verify

Tutorial = 学ぶ
Catalog  = Example を探す（:4200）
           ├─ 実行 → Example Server（:4173）
           └─ 編集 → Editor（:8080）→ workspace/
Runtime  = chirimen-server（:33330）

Catalog（:4200）は題材の発見入口です。編集結果の確認先ではありません。

Port Service Role
33330 chirimen-server Hardware Runtime / WebSocket
8080 chirimen-editor Browser Editor / code-server
4173 chirimen-examples Example Server / Runtime Examples
4200 chirimen-example-catalog Example Catalog

詳細は Browser Development を正本とします。実機 E2E は Compatibility に記録します。

推奨環境

  • Raspberry Pi 3 B+（Runtime-only。on-device Docker build は Unsupported）
  • Raspberry Pi 4（Runtime / Development。Docker build Supported）
  • Raspberry Pi 5（Runtime / Development。Docker build Supported）

サポート対象は Raspberry Pi OS 64-bit。

Recommended: Raspberry Pi OS Lite 64-bit

Runtime Support と Development / Docker Build Support の区別の正本は Compatibility です。

32-bit OS は非推奨です。 詳細を見る

使う

題材探しは Example Catalog（:4200）です。ported の「実行」は Example Server（:4173）、「編集」は Editor（:8080）から host workspace/ へ保存します。docs/examples は回路仕様と出典であり、編集場所ではありません。

  • GPIO LED Blink

  • I2C Scan （Runtime Example。確認先 :4173/i2c-scan/）
    • 検証仕様
  • Troubleshooting
  • 出典・仕様（編集場所ではありません）
    • Example Catalog と Legacy 資産の出典・責務
    • Legacy Example 移植対象一覧

    • 回路図の再利用と Pi 3 / 4 / 5 互換性
